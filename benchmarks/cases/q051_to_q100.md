# Benchmark Cases: Q051–Q100

**Benchmark repositories:**
- `sable` — a fictional open-source Rust HTTP router/web framework (primary benchmark target)
- `meridian` — a fictional open-source TypeScript UI component library (used for cross-repo dependency cases)

All queries below are questions a developer would ask Attic *about sable or meridian*, not about Attic itself.

**Category coverage:** Architecture Explanation, Impact Analysis, Cross-Repo Dependency, Knowledge Question, Generic Search  
**Answer mode mix:** FAST (10%), NORMAL (50%), DEEP (40%)  
**Format per case:** same as q001_to_q050.md
