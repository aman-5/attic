# Benchmark Cases: Q001–Q050

**Category coverage:** Definition Lookup, Symbol Navigation, Configuration Lookup, Debugging Root Cause, Test Behavior  
**Answer mode mix:** FAST (30%), NORMAL (50%), DEEP (20%)  
**Format per case:**
- `ID` — stable identifier
- `Type` — QueryType from query_evidence.md
- `Mode` — expected AnswerMode
- `Query` — verbatim query string
- `Expected evidence` — minimum evidence contract that must be satisfied
- `Pass criteria` — what the answer must contain to be considered correct
- `Latency target` — wall-clock SLA (ms)
